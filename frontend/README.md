# Pixel Agent Office 프런트엔드

Pixel Agent Office의 웹 앱입니다. React, TypeScript, Vite를 사용합니다.

## 로컬 실행

Node.js와 pnpm이 설치된 상태에서 저장소 루트에서 실행합니다.

```powershell
Set-Location frontend
pnpm install --frozen-lockfile
pnpm dev
```

터미널에 표시된 `Local` 주소를 브라우저에서 엽니다.

## 린트 및 빌드

`frontend/`에서 실행합니다.

```powershell
pnpm lint
pnpm build
```

프로젝트 소개와 개발 계획은 [루트 README](../README.md)를 참고하세요.
