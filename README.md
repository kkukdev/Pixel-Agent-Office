**Pixel Agent Office**는 라즈베리파이 홈서버에 직접 설치해 쓰는 1인용 AI 업무 플랫폼입니다. 에이전트가 PR을 리뷰하거나 코드와 리서치 보고서를 만들면, 16비트풍 사무실의 캐릭터가 실제 작업 상태에 맞춰 움직입니다. PC와 모바일에서 작업을 지시하고, 승인 요청에 응답하고, 결과를 확인할 수 있습니다.

> **개발 상태** · 초기 개발 단계입니다. 아래 기능과 기술 스택은 첫 릴리스 계획을 기준으로 소개합니다.

## 주요 기능

- **실시간 픽셀 오피스** — PM, Planner, Researcher, Developer, QA, Editor가 업무 좌석 15석을 갖춘 사무실에 배치됩니다. 캐릭터에 작업 중, 승인 대기, 완료 상태가 표시됩니다. 서버의 전역 동시 실행 기본값은 2개입니다.
- **역할 지정과 PM 협업** — `@dev`처럼 역할을 직접 지정하거나 큰 목표를 PM에게 맡깁니다. PM은 목표를 단계별로 나누고 필요한 역할에 작업을 배분합니다.
- **GitHub 리뷰와 개발** — 연결한 저장소의 PR을 직접 선택하거나 Webhook으로 리뷰를 시작합니다. 허용된 범위에서 코드 수정과 PR 생성을 진행하고, GitHub Actions로 빌드와 테스트를 실행하며, 필요하면 QA가 결과를 검토합니다.
- **예약 리서치** — 보안 뉴스처럼 반복해서 필요한 조사를 예약합니다. 지정 시각에 시작할지, 그 시각까지 결과 전달을 목표로 할지 선택할 수 있습니다.
- **작업별 권한과 복구** — 코드 작업은 지정한 저장소 하나에 한정합니다. 작업별 A/B/C 권한의 기본값은 B(반자율형)이며, 추가 권한이 필요하면 웹에서 승인을 요청합니다. 서버를 재시작해도 작업 큐, 예약, 승인 대기 상태를 복구합니다.

## 기술 스택

| 영역         | 기술                                            | 용도                                              |
| ------------ | ----------------------------------------------- | ------------------------------------------------- |
| 프런트엔드   | React, TypeScript, PixiJS                       | 작업·승인 대시보드와 2D 픽셀 오피스               |
| 백엔드       | Python, FastAPI                                 | REST API, 작업 스케줄링, 에이전트 실행, 권한 검사 |
| 데이터 저장  | SQLite                                          | 영속 작업 큐, 예약, 승인, 실행 이력               |
| 실시간 통신  | Server-Sent Events(SSE)                         | 작업 및 캐릭터 상태 변경 전달                     |
| AI 모델      | NVIDIA Build 등 외부 LLM API                    | 공급자와 역할별 모델 선택                         |
| GitHub       | GitHub App, Webhooks, GitHub Actions            | 저장소 접근, PR 이벤트 수신, 외부 CI 검증         |
| 배포 및 인증 | Docker Compose, Nginx, Cloudflare Tunnel·Access | 라즈베리파이 배포, 외부 접속, 단일 관리자 인증    |

## 개발 계획

1. **첫 알파** — 연결된 저장소의 PR 한 건을 실제 LLM으로 리뷰합니다. 결과를 SQLite에 기록하고 SSE로 작업 상태를 전달해 웹 보고서와 캐릭터에 반영합니다.
2. **첫 릴리스** — PM 협업, 예약 리서치, GitHub 개발·CI·QA를 연결합니다. PC와 모바일에서 작업을 지시하고 승인하며, 서버 재시작 후 작업 복구와 수동 백업·복원을 검증합니다.
3. **후속 릴리스** — 자동 백업, 외부 보관, 웹 복원 관리, Telegram·Discord 연동을 확장합니다.
